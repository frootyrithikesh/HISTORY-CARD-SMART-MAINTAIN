IMPORTANT – GOOGLE DRIVE PERMISSIONS
For each of the 25 files, open Share > General access > Anyone with the link > Viewer.
If BPCL policy does not permit public-link access, do not use this method; use an approved authenticated storage service instead.

DEPLOY
1. Extract this ZIP.
2. Replace the root index.html in your existing GitHub Pages repository.
3. Keep the repository's existing backend deployment unchanged; this is a frontend photo-map change.
4. Commit changes and wait for GitHub Pages to publish.
5. Open the website and hard refresh (Ctrl+F5).
